Versions / Installation

Aucune image officielle n’est encore publiée.

Il n’existe pas d’ISO Deku Linux ni d’installateur de production. Cette page sera mise à jour lorsque les images auront été construites, vérifiées et testées.

Pas de téléchargement officiel disponible. Évitez les fichiers tiers qui se présentent comme des images officielles de Deku Linux.

Conditions avant une première version

  1. Fixer la base du système, le noyau, les architectures et le périmètre matériel.
  2. Construire une image dans une chaîne contrôlée, avec entrées figées et provenance enregistrée.
  3. Vérifier les métadonnées signées, les empreintes et la rotation des clés de publication.
  4. Tester l’installation et le démarrage dans des machines virtuelles jetables.
  5. Tester les mises à jour, les erreurs, le retour arrière et le démarrage avec un noyau précédent.
  6. Publier les notes, limitations, sommes de contrôle et instructions de vérification.

Contenu d’une page de version

Chaque publication précisera la version, la date, l’architecture, la taille, l’empreinte SHA-256, les instructions de vérification de signature, les révisions source et les limites connues.

Pourquoi attendre ?

Une image qui démarre une fois n’est pas une distribution prête à l’usage. Le projet doit démontrer les mises à jour, la récupération après échec, l’intégrité des paquets et un chemin de démarrage fonctionnel.

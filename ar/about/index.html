المؤسسة / نبذة

مؤسسة مفتوحة المصدر لمشاريع مستقلة ومفيدة.

Deku Foundation هي الواجهة العامة لجهد هندسي مستقل يضم عدة مشاريع. Deku Linux هو أول مشروع منصة؛ أما البحث في لغة البرمجة وممارسات التطوير المشتركة فهي مسارات منفصلة لكل منها نطاق وحالة نضج محددان.

الرسالة

تطوير برمجيات مفتوحة المصدر مفيدة وقابلة للصيانة ومتاحة للجميع من خلال هندسة شفافة وإعادة استخدام مدروسة للمشاريع الأصلية وقرارات قابلة للاختبار. قد تشمل المحفظة أنظمة التشغيل وأدوات المطورين وتقنية برمجة عربية أولًا، دون فرض حزمة تقنية واحدة على كل مشروع.

توضيح النطاق: «Deku Foundation» هو الاسم العام لهذه المؤسسة الهندسية. لا تدّعي هذه الصفحة تسجيلها كجهة غير ربحية، أو حصولها على اعتماد، أو جاهزية أي مشروع للإنتاج.

محفظة المشاريع الحالية

  • Deku Linux — نموذج أولي: بيانات الحزم وتخطيط الاعتماديات والتحقق من خطط البناء وملفات تكوين النظام وخطط تثبيت غير مدمرة. لا توجد صورة ISO عامة أو مستودع حزم إنتاجي أو إصدار مدعوم.
  • لغة برمجة عربية أولًا — مقترح: يبدأ الاتجاه المقترح بنموذج أولي مستضاف على Rust، مع قواعد صريحة لـ Unicode والنص ثنائي الاتجاه والتشخيص والتكامل. لا ندّعي وجود مترجم أو مستودع مستقل للغة حتى الآن.
  • الهندسة المشتركة — ممارسات: التكامل المستمر ومراجعة سلسلة التوريد وتقييم المشاريع الأصلية والتوثيق والتوطين ومعايير الإصدار أعمال مشتركة بين المشاريع، وليست منتجات منفصلة دون تنفيذ مُصان.

كيف تتقدم المشاريع

  1. البحث: تحديد حاجة المستخدم ومراجعة البدائل الناضجة وتوثيق التراخيص والصيانة والمخاطر الأمنية.
  2. المواصفات: كتابة مقترح أو قرار معماري يعرض البدائل ومعايير خروج قابلة للقياس والقيود المعروفة.
  3. النموذج الأولي: إبقاء التغييرات في dev واختبار أصغر مسار متكامل مفيد ونشر أدلة نتائج CI.
  4. الترحيل: تحديث main بعد نجاح الاختبارات المطلوبة والتوثيق ومراجعة المخاطر. نجاح سير عمل يعني اجتياز الفحوص المحددة فقط، ولا يعد اعتمادًا أمنيًا أو إثباتًا لجهوزية الإنتاج.

المبادئ

  • الأصل أولًا: تهيئة مشروع أصلي مُصان أو دمجه أو حزمُه أو المساهمة فيه قبل إنشاء تشعب طويل الأمد.
  • الانفتاح افتراضيًا: ينبغي أن تكون الشيفرة والقرارات والمسائل والقيود متاحة للمراجعة.
  • مسؤوليات واضحة: لا مستودع دون ميثاق ومسؤول ومرحلة أولى قابلة للاختبار.
  • التواصل المدعوم بالأدلة: التمييز بين المقترحات والنماذج الأولية والإصدارات المستقرة والمشاريع المؤرشفة، دون اختلاق أرقام أو تواريخ أو مزايا.

المشاركة

راجع مستودعًا حاليًا أو أبلغ عن مشكلة قابلة لإعادة الإنتاج أو حسّن التوثيق والترجمة أو ناقش مقترحات اللغة والبنية. ابدأ من دليل المستودعات وروابط المساهمة الموجودة فيه. يجب إبقاء بلاغات الثغرات الحساسة خاصة واتباع سياسة المستودع المعني.

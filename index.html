Independent open-source engineering

Build in the open.
Across technologies.

Deku Foundation is an independent open-source engineering organization. Deku Linux is its first platform project. The foundation is also researching an Arabic-first programming language and reusable developer tooling. These efforts remain proposals until working code and evidence exist.

01 / Project portfolio

Several projects.
Clear boundaries.

The foundation is not synonymous with one operating system. Each workstream should have a written purpose, an owner, a testable milestone and an honest maturity label before it grows.

01 / PLATFORM
◇

Deku Linux

The first platform project. Its public repositories prototype package metadata, dependency planning, build-plan validation, system manifests and non-destructive installation planning. No installable release is available.

02 / Operating principles

Reuse what works.
Own the integration.

Independent engineering does not mean rebuilding every component. It means setting clear goals, choosing suitable upstream projects, maintaining integration quality and being accountable for what is shipped.

01
◎

Research before implementation

Compare maintained upstream projects against requirements, license, security updates, operational cost and recovery behavior before starting a replacement.

Read the technical evaluations ↗
02
⌁

Keep trust boundaries narrow

Reviewed changes, pinned inputs, least-privilege CI and a separation between building, signing and publishing are design constraints—not release claims.

Review current security constraints ↗
03
↻

Promote only proven work

Develop and test on dev first. Update main only after the relevant checks pass; a green CI run proves those checks passed, not that a full distribution is production-ready.

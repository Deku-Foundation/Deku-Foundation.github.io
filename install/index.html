03 / Installation

Not ready to install — yet.

Deku Linux does not currently publish an official ISO or installer. This page will be updated when a build can be tested and its provenance verified.

Explore DekuAbout the projectDocumentationInstallation statusSecurityContributingFAQRoadmapProject repository ↗
No official download is available. Do not use third-party files claiming to be official Deku Linux images.

What needs to happen first

  1. Choose and document the initial platform and supported hardware scope.
  2. Build a minimal image in an isolated, traceable pipeline.
  3. Test booting and installation in virtual machines and representative hardware.
  4. Verify package sources, image checksums, and release signatures.
  5. Test update, rollback or recovery, and documented failure handling.
  6. Publish release notes, known issues, support expectations, and reproducible instructions for the build.

When a release is published

The official release page will include the exact version, publication date, architecture, file size, SHA-256 checksum, signature-verification instructions, source revision, and known limitations. No download link will be shown here until a real release exists.

Want to help test?

Follow the roadmap and contribute through the contribution guide. Early testing should focus on reproducible reports and clearly identified test environments.

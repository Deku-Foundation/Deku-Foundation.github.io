06 / FAQ

Clear answers, without hype.

Frequently asked questions about the project’s goals, status, and technical direction. Answers will change as decisions are tested and implementation advances.

Explore DekuAbout the projectDocumentationInstallation statusSecurityContributingFAQRoadmapProject repository ↗

Can I download Deku Linux now?

No. There is no official ISO or installation image yet. See installation status for the criteria that must be met before a release is published.

Is Deku based on Void Linux?

Deku takes inspiration from independent, maintainable Linux projects, including Void’s focus on packaging and a lean system. No final base distribution or complete upstream code import has been approved. Technical options are being evaluated explicitly.

Which package manager and init system will it use?

These decisions are not final. The project is evaluating mature options against compatibility, maintenance burden, security, update behavior, and recovery requirements. Proposals should be recorded and tested before adoption.

Will Deku be rolling release?

No release model has been finalized. A rolling model would require reliable upgrade tests, recovery paths, and sustainable maintenance capacity.

Will it be free and open source?

The project aims to remain free and open source. Each component will need its own license review and attribution. The license of a project-owned file does not automatically change the license of upstream components.

When will the first release arrive?

There is no announced release date. The project will publish an image when defined engineering and verification criteria are met, rather than committing to an unsupported date.

How can I help?

Start with the contribution guide, review the roadmap, or open an issue in the relevant GitHub repository.

Where can I report a security issue?

Read the project’s security policy ↗ and use a private reporting path where available. Do not publish secrets or exploit details in a public issue.

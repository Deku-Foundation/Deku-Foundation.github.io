Visual privacy

deku-satr

Experimental Android app

Deku Satr is a native Android prototype that applies an on-device person-segmentation mask to people visible on screen. Model coverage is imperfect and can miss small or distant people; it is not guaranteed privacy protection. The repository documents model evaluation, capture limits and privacy boundaries.

04 / Intended engineering flow

Connect the parts. Keep the gates explicit.

This is the target sequence, not an end-to-end pipeline that exists today. Each transition requires evidence and working integration.

Review recipes

Pin upstream inputs, license metadata, dependencies and patch notes.

Validate plans

Check constraints and reject unsafe or ambiguous build/package inputs.

Build artifacts

Native package builds, isolated workers and production provenance are not implemented; the upstream-based ISO experiment is still being debugged.

Publish trusted packages

Production signing, repository publication and mirrors are not available.

Compose and boot

Experimental ISO assembly is under test; VM boot, installation and release validation remain unproven.

05 / Current boundary

Clarity is part of the product.

Deku Foundation is a multi-project open-source organization. Deku Linux is its platform workstream; the directory also includes Rukn, Android applications and shared engineering tools. Each project follows its own maturity and release gates.

Review the release status ↗
  • No official ISO or supported release.
  • No production package repository.
  • No isolated production build service.
  • No release-signing or mirror service.
  • No installer that writes to real disks.
  • No ISO build has yet passed boot acceptance.

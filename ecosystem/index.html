04 / Intended engineering flow

Connect the parts. Keep the gates explicit.

This is the target sequence, not an end-to-end pipeline that exists today. Each transition requires evidence and working integration.

Review recipes

Pin upstream inputs, license metadata, dependencies and patch notes.

Validate plans

Check constraints and reject unsafe or ambiguous build/package inputs.

Build artifacts

Sandboxed execution, provenance and artifact production are not implemented.

Publish trusted packages

Production signing, repository publication and mirrors are not available.

Compose and boot

System image assembly, VM install and release validation remain future gates.

05 / Current boundary

Clarity is part of the product.

Deku Linux remains a foundation-stage project. Public source and documentation are available; the operating-system release and production delivery services are not. This portal intentionally separates working prototypes from planned infrastructure.

Review the release status ↗
  • No official ISO or supported release.
  • No production package repository.
  • No isolated production build service.
  • No release-signing or mirror service.
  • No installer that writes to real disks.
  • No bootable system-image pipeline.

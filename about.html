A Linux project built around clear decisions.

Deku Linux is an independent, open-source distribution in its foundation stage. The goal is a coherent, maintainable system built with evidence rather than unsupported promises.

What Deku is

Deku Linux is a project to develop a general-purpose Linux distribution with a thoughtful user experience, transparent engineering, and long-term maintainability. The project is early-stage: its public work currently focuses on governance, architecture evaluation, packaging standards, and build-system foundations.

Current status: planning and prototyping. There is no public installation image or production release at this time.

What guides the work

  • Open development: decisions, issues, source changes, and project policies should be reviewable.
  • Reuse mature technology: adopt established components where they meet requirements, while respecting upstream licenses and maintainers.
  • Security as engineering: track sources, isolate builds, review changes, and separate build, signing, and publishing privileges.
  • Test reliability: define and measure upgrade, recovery, compatibility, and release criteria before making claims.

What Deku is not yet

Deku does not currently claim production readiness, a stable release channel, reproducible builds, a completed security audit, or a working downloadable ISO. These are goals that require implementation and verifiable evidence.

Project structure

Project & governance ↗Roadmap, policies, and architecture decisions.Packages ↗Packaging standards and upstream research.Build system ↗Build pipeline and validation work.Infrastructure ↗Deployment and operational boundaries.

How decisions are made

Significant technical choices should be recorded as Architecture Decision Records (ADRs), including context, alternatives, trade-offs, status, and evidence. Proposed decisions remain proposals until explicitly accepted.
